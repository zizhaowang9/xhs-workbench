# 素材 2/3　主播基本功四要素（20 分 09 秒，口播：9527）

## 内容摘要

**镜头状态（播感）**：眼神看镜头不看屏幕，看弹幕瞟一眼马上回来；表情随话题变化；减掉多余小动作（频繁眨眼、撇嘴、咬嘴唇、翻白眼、摸头发、看手机）；半身出镜坐姿挺拔不瘫不靠、手部动作在画面内、不长期歪头低头、距离稳定；声音气息平稳、重点放慢加停顿、语气分层、去掉“哇啊嗯哦”口头禅；状态持续（无人时不垮、开播前十分钟预热、情绪隔离）。
**互动承接（留人）**：进人必须先点名欢迎，不笼统“欢迎所有人”；陌生人轻欢迎＋一个问题，老粉加专属问候；生僻 ID 说“欢迎这位名字很难打的朋友”。弹幕有问必回、先共情再延伸、听完不打断；分型处理（夸奖→感谢＋拉全场、闲聊→接上再抛、提问→先答清再引导、抬杠→不纠缠简短转场）。空窗期用开放式提问＋话题库。**冷场禁忌**：沉默发呆、反复追问“是不是都是人机/怎么都不说话”。分层互动：路人要停留＋点名抛问题，停留观众引导打字，粉丝记喜好稳回访；灯牌/关注/点赞要在氛围到了顺势提。
**节奏控场（稳场）**：整场拆四段——开场拉新、中段升温、高潮放大情绪并引导关注、收尾十分钟沉淀并预告下次。话题会抛也要会收，往负面/敏感走时刹车。抬杠引战不反复回应、严重就禁言且不解释，**不与观众对线**。
**话术转化（变现）**：观众买的是被看见、被重视的情绪价值，不是主播伸手要。轻转化（关注、灯牌）高频自然，重转化（礼物）等情绪高点。礼物感谢分档：小额答谢带热全场、中额加情绪给专属感、大额放大惊喜再同时感谢全场；感谢完不全程只跟一个人聊。顺势聊礼物要有前提（气氛好、有人互动），冷场不提；“量力而行”反复说。
